## 今回の追加監査と修正

### 雷神（card_0427）の固定コスト設定

保存効果文は「自分の手札の[雷]の魔法のコスト=0。」。従来の `effectiveCardCost` は数値のコスト減少には対応していたが、属性指定の固定コスト設定を処理していなかった。これはfixture不足ではなく、実際の常在効果の実装漏れ。

PR #40 で以下を修正した。

- 場にいる有効な雷神が、自分の手札の[雷]の魔法のコストを0に設定。
- 雷以外の魔法には適用しない。
- 雷神の効果が無効化されている場合は適用しない。
- 帯電の矢（card_0602、コスト4）は0、氷の雨（card_0608、コスト4）は4、雷神の効果無効化後は帯電の矢も4になるブラウザ回帰テストを追加。

PR #40 の `npm run test:all` と全CI工程は成功。監査時点ではPR未マージのため、mainへ反映済みとは扱わない。

### 追加の手動監査候補

- **糸動源（card_0448）**: 「自分の[地,機械]1体は『自分のターン終了時まで、これの()効果のエネルギー=1。』を持つ。」。現行ソースには付与効果を実行する汎用処理や、起動能力の実効エネルギーコストを上書きする処理が見当たらず、実装漏れの可能性が高い。対象選択、複数起動能力への適用、ターン終了時の解除、オンライン同期を専用テストで確認する。
- **魔泡の魔王（card_0357）**: 「手札にある時、場のモンスターが4体以上同名なら、場にこれのコスト=1。」。固定コスト設定の可能性があるが「場にこれのコスト=1」の表現が不明瞭。カード原本・ルール意図を確定するまで実装しない。
- **VOID（card_0564）第3句**: 「自分の相手の手札1枚ずつを捨てる。」。OCR原本と保存データが一致するが意味が不明瞭。対象・枚数・選択権を推測して実装しない。自動監査上の唯一の明確な未実装候補。
